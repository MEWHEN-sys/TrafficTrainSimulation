# Physical Computing Project 2026 - IT KMITL
## ปัญหา: 
* จุดตัดทางรถไฟที่ใช้คนควบคุมทางกั้น ต้องพึ่งความตื่นตัวของเจ้าหน้าที่ จึงเกิด human error ได้ เช่น ลืมปิดทางกั้น ปิดช้า หรือไม่ทันเห็นรถไฟ
* ประตูอาจปิดเร็วเกินไป (ผู้ใช้ถนนต้องรอนาน) หรือปิดช้าเกินไป (อันตราย)
* ต้องมีคนประจำที่ทางข้ามตลอดเวลาทำให้ต้องจ่ายค่าแรงที่เยอะ

## ความสำคัญ
ถ้าทางกั้นไม่ปิดหรือปิดช้า อาจเกิดอุบัติเหตุรุนแรงระหว่างรถไฟกับรถยนต์หรือคนเดินถนน ซึ่งเสี่ยงต่อชีวิตและทรัพย์สิน และ สามารถลดค่าใช้จ่ายระยะยาวได้จากค่าแรง

## ผู้ได้ประโยชน์
ผู้สัญจรทางถนนที่ผ่านจุดตัด, ผู้ควบคุมทางกั้น (ลดภาระและความเสี่ยง), ผู้โดยสารและพนักงานรถไฟ
วิธีแก้: ใช้ Micro controller กับ sensor ตรวจจับรถไฟที่กำลังเข้าใกล้ แล้วแจ้งเตือนผู้ควบคุมผ่าน Wi-Fi เพื่อให้ยืนยัน จากนั้นสั่งปิดทางกั้น
